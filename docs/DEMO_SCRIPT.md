# Demo Script (3 Minutes)

This is your video submission script. Every retrieval decision, UI element, and agent behavior should be tuned so these three queries work perfectly.

---

## Problem Statement (0:00 - 0:20)

"Student org leaders spend hours every week trying to remember what was decided, what events went well, and how to plan what's next. When people graduate, all that knowledge walks out the door. We built an agent that makes a year of organizational history instantly queryable and actionable  -  so your org's intelligence never graduates."

Brief flash of: messy Drive folders, Discord history, scattered docs → then the clean agent interface.

---

## Demo Arc

This demo builds. Query 1 establishes trust (grounded retrieval). Query 2 shows depth (cross-doc synthesis). Query 3 is the climax  -  the agent takes action. Narrate it that way. Don't treat the three queries as equal; they escalate.

The money shot is the Google Doc appearing in Drive. Slow down there. Say the words: "The agent didn't just answer  -  it created something."

---

## Query 1  -  RECALL (0:20 - 1:00)

**Query typed:** "What were the key logistics challenges at Hacklanta and how did we solve them?"

**Expected mode badge:** RECALL (blue)

**Expected answer should cite:**
- Hacklanta Master Doc - Spring 26
- Saxby's meeting notes (venue negotiation)
- Hacklanta Run of Show

**Expected answer content should include:**
- Venue booking challenges at GSU
- Check-in flow problems and how they adapted
- Run of show timing adjustments
- Specific decisions made in the lead-up

**What to show on screen:**
- The citation cards appearing under the answer with source doc names and dates
- Clicking a citation link opens the Google Drive doc

**This proves:** The agent retrieves specific, grounded, real information from actual org documents. Not hallucinated.

---

## Query 2  -  ANALYZE (1:00 - 1:45)

**Query typed:** "How has our event attendance grown from Fall 2025 to Spring 2026, and which events drove the most engagement?"

**Expected mode badge:** ANALYZE (purple)

**Expected answer should cite:**
- Combined Attendance (aggregate)
- Growth Master Doc
- EVENT SCHEDULE FALL 2025

**Expected answer content should include:**
- Specific numbers: Fall 2025 events, Spring 2026 events
- Hacklanta as the growth spike (400+ attendees, $20k sponsors)
- Claude Workshop (200+ attendees)
- Trend line: smaller events → major hackathon → continued growth

**Confirmed stats to verify against:**
- Hacklanta: 400+ attendees, $20,000 in sponsorships, $5,000+ in prizes, 12 hours, 5 weeks to organize
- Claude Workshop: 200+ attendees, Tyler Sztuka as Anthropic ambassador

**While spinner is showing** (scripted messages cycling on screen):
Say this while the spinner runs through "Searching Fall 2025 event records…" → "Pulling Spring 2026 attendance data…" → "Cross-referencing sources…" → "Identifying what drove growth…":

"This is a different mode entirely. Instead of looking up one event, it's reading across every attendance record we have  -  Fall 2025, Spring 2026  -  and synthesizing a trend. Watch the sources when it loads."

**When response loads:**
"You can see it pulled from three different documents  -  none of them wrote the same answer. The agent synthesized that. The table is built from real numbers in our records, not estimates."

Pause on the citation cards. Say: "Three sources, one answer. That's cross-document synthesis."

**What to show on screen:**
- Multiple citation cards showing synthesis across sources
- The answer is clearly cross-document, not from one file

**This proves:** The agent can synthesize across multiple sources, not just retrieve from one doc.

---

## Query 3  -  PLAN / Climax (1:45 - 2:30)

**Narration before typing the query:** "Now here's where it gets different from every other RAG demo you've seen."

**Query typed:** "Draft a planning brief for our next major hackathon based on everything we learned from Hacklanta."

**Expected mode badge:** PLAN (green)

**What should happen:**
1. Agent shows "Analyzing Hacklanta learnings..." (streaming)
2. Agent retrieves from: Hacklanta Master Doc, Run of Show, Prizes, Finance, post hacklanta growth stuff
3. Agent generates a structured planning brief
4. At the bottom: "Creating Google Doc..." → spinner
5. Google Doc link appears: "[AI Generated] Planning Brief  -  Next Hacklanta  -  2026-06-XX"
6. Click the link  -  the real Google Doc opens in Drive with the full brief

**The Google Doc should contain:**
- Title: "Hacklanta II Planning Brief  -  Generated by progsu Intelligence Agent"
- Section: What Worked (from post-event docs)
- Section: What to Improve (from meeting notes + feedback)
- Section: Recommended Timeline (from Run of Show learnings)
- Section: Sponsorship Strategy (from Partnership Opportunities + Finance)
- Section: Sources Referenced (list with Drive links)
- Footer: "Generated by progsu Intelligence Agent on [date]"

**While spinner is showing** (scripted messages cycling on screen):
Say this while the spinner runs through "Pulling Hacklanta learnings…" → "Reviewing run of show and logistics…" → "Drafting Hacklanta II recommendations…" → "Building sponsorship strategy…" → "Assembling your planning brief…":

"This is PLAN mode. It's not just finding an answer  -  it's reading five sources, synthesizing a structured document, and in a moment it's going to create a real artifact in Google Drive. This is what makes it an agent, not a search tool."

**When response loads:**
When the brief preview appears in chat, say: "There it is. But that's not just text in a chat window."

Pause. Then click the Google Drive link. Say: "The agent didn't just answer  -  it created something."

Keep the Google Doc on screen for at least 5 seconds while scrolling. Say: "What worked at Hacklanta, what to improve, the full timeline, sponsorship strategy  -  all grounded in the actual documents from the event. This took five weeks and a whole team to run the first time. This took the agent ten seconds to brief."

**What to show on screen:**
- The plan text streaming in the chat
- The Google Doc link appearing  -  pause here, let it land
- Say out loud: "The agent didn't just answer  -  it created something."
- Click through to show the actual doc open in Drive  -  keep it on screen for 5+ seconds
- Scroll through the doc sections while narrating

**This proves:** The agent takes multi-step action: retrieves from 5+ sources, synthesizes a plan, creates a real artifact in Drive. This is the "accomplish multi-step tasks" requirement from the hackathon judges.
